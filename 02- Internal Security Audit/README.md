# Internal Security Audit

> An internal security audit completed as part of the **Google Cybersecurity Professional Certificate – Course 2**.

---

## Overview

This activity involved conducting an internal security audit for **Botium Toys**, a fictional company, to assess its existing security controls and compliance practices.

The audit focused on identifying security weaknesses, evaluating the controls currently in place, and assessing the company's compliance with relevant security standards and regulations.

---

## Key Highlights

- Defined the scope and goals of the security audit
- Identified and assessed the company's current assets
- Evaluated existing security controls and identified missing controls
- Conducted a risk assessment and assigned a risk score
- Reviewed compliance with **PCI DSS, GDPR, and SOC 1 / SOC 2**
- Developed recommendations to improve the company's overall security posture

---

## Key Findings

The audit identified several areas requiring improvement, including:

- Lack of least-privilege access and separation of duties
- No disaster recovery plan or critical data backups
- Lack of encryption for sensitive customer information
- No intrusion detection system (IDS)
- Weak password policies and no centralized password management
- Incomplete asset management and classification

The overall risk score was assessed as **8/10**, indicating a relatively high level of risk.
